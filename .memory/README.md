# .memory —— 项目工作记忆（随仓库同步到 GitHub）

本目录是**超级大脑项目自身的长期工作记忆**，提交进 Git，用于跨设备/跨 Agent 续接开发。

## 纪律

1. **禁止放入任何密钥**：PAT、token、`.env` 内容、私库地址里的凭据一律不进这里（本目录会推到 GitHub）。
2. **只写"不可从代码推导"的信息**：为什么这么决策、踩过什么坑、当前进度与下一步。
   能从 `git log` / 代码本身看出来的东西不重复记录。
3. **按主题组织，不按日期堆流水账**：`WORKING_MEMORY.md` 保持滚动更新，过期条目直接改写或删除。
4. **每完成一个阶段（阶段 0~6）必须回来更新 `WORKING_MEMORY.md`** 的进度与遗留问题。

## 文件

| 文件 | 用途 |
|---|---|
| `WORKING_MEMORY.md` | 当前进度、下一步、已知坑（滚动维护） |
| `DECISIONS.md` | 实现级决策记录（ADR 简版）：选型理由与被否决方案 |
| `ACCEPTANCE.md` | 七阶段验收标准与实测结论（对着架构 §十一 打勾） |
